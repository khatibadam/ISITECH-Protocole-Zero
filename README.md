# Protocole Zéro VR (ISITECH)

> **Projet de groupe** : court jeu d'horreur psychologique en réalité virtuelle (~6-8 min), dans une reproduction de l'étage d'ISITECH.

## Équipe

- **Adam K.** : code & conception
- **Nayir S.** : game design

## Stack

Unity 6000.3.18f1 · URP · XR Interaction Toolkit 3.2.1 · OpenXR.

## Lancer

- **Scène** : `Assets/Scenes/01_ProtocoleZero_MVP.unity` (build index 0).
- **VR** : brancher un casque OpenXR (Quest via Link/AirLink, ou autre) puis **Play**.
- **Desktop (sans casque)** : **Play** suffit, `SimplePlayerController` + le XR Interaction Simulator prennent le relais.

## Contrôles desktop

| Action | Touche |
|---|---|
| Se déplacer | **ZQSD** (relatif au regard) |
| Regarder | **Clic droit maintenu + souris** |
| Rotation rapide | **A / E** |
| Interagir | **F** |

## Déroulé

1. **Salle info (Mars)** : réveiller le PC, lire l'objectif.
2. **Couloir vitré** : rejoindre le local serveur.
3. **Local serveur** : brancher les câbles du panneau électrique, coupure de courant.
4. **Hall** : ouvrir la porte finale à deux mains. Un jumpscare peut se déclencher près des ascenseurs.
